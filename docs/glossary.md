# Glossary

- **Advanced packaging:** assembling chips into higher-performance packages, such as stacked memory or several chiplets in one package.
- **Appraisal cost:** money spent checking quality.
- **Chiplet:** a small chip designed to be combined with others in one package.
- **Cost of quality:** the sum of checking costs and failure costs.
- **Detection rate:** the chance an inspection spots a defect that is present.
- **Escaped defect:** a defective unit that reaches the customer.
- **HBM (high-bandwidth memory):** stacked memory chips that sit close to a processor.
- **In-line inspection:** checking units during production, between steps.
- **Inspection plan:** the share of units checked after each step.
- **Monte Carlo simulation:** estimating an average by simulating many random cases.
- **Scrap:** the value lost when a defective unit is thrown away.
- **Sensitivity analysis:** testing how much the answer changes when an assumption changes.
- **Throughput:** how many units the line completes per unit of time.
